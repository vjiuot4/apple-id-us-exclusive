## 拿到号第一个小时：按这个顺序做，别跳步

这一段是本文最该认真看的部分。买号的钱是小事，顺序做错导致号废掉、或者号还在但控制权不在你手里，才是真正的损失。

### 第一步：先验号，别急着改东西

拿到账号信息后，先做一轮检查，任何一项不通过就立刻找客服换号或退款，不要自己想办法修：

1. 能否登录 appleid.apple.com 并看到完整账户信息
2. 能否修改密码，且新密码确实生效
3. 能否添加自己的双重认证手机号，并把卖家的号码删掉
4. 登录设备列表里有没有陌生设备，有就全部移除
5. 购买记录里有没有异常消费或未授权订阅
6. 能否修改账单地址和安全问题答案
7. 能否开启"查找我的 iPhone"，确认设备控制权在自己手上

这套清单来自一份验号流程整理，各项和平台自己给出的操作顺序不冲突。第 3 项和第 4 项最容易被跳过，也最要紧：设备列表里留着别人的设备，等于这个号还有第二把钥匙。

### 第二步：先换绑手机号，再改密码

顺序不能反。原因很具体：改密之后，原来绑定的虚拟设备就收不到验证码了。如果你先改密再换绑，中间那一步可能直接卡死，登不进去也验证不了。

正确顺序是：登录 appleid.apple.com → 用买来的账号和密码进入 → 到"安全"板块先把自己手机号添加为受信任号码并完成验证 → 确认生效后再改密码 → 最后同步更新密保问题答案。邮箱也一并换成自己的，救援邮箱建议和主邮箱用不同服务商（比如主用 Gmail、救援用 Outlook），避免一个邮箱出问题两个都找不回。

密保问题的三个答案改完立刻截图存好。这类账号找回时，密保答案往往比密码更管用。

### 第三步：只登 App Store，不登 iCloud

这一条在平台商品页、多篇教程里的表述完全一致：买来的号只在 App Store 登录，不要去"设置"里登 Apple ID。

操作路径是打开 App Store → 点右上角头像 → 滑到底部退出当前账号 → 在顶部输入买来的美区账号密码登录。iCloud、通讯录、照片、备份继续用你自己的国区账号，两边互不影响。

iCloud 登录会触发设备绑定、"查找我的 iPhone"、照片同步这一串动作，海外号登 iCloud 被风控的概率明显更高。确实需要 iCloud 功能，就买上面表里那档已激活 iCloud 的批量款，别拿普通号去试。

### 第四步：开双重认证，然后下载、切回、再开 App

开启双重认证的路径是：设置 → Apple ID → 密码与安全 → 双重认证。绑自己的手机号，之后在新设备登录都要验证码，别人拿到密码也进不去。

下载环节有一个高频错误：用美区号下完 App，直接就在美区号还登着的状态下打开使用。后果是游戏内购、App 内订阅全部走这个买来的号，号一旦被封，存档和已购内容一起没。正确做法是用美区号下载完，退出，切回自己的国区号，再打开 App。已经下载的 App 不会因为切号被删掉，只是后续更新时需要回到当初下载它的那个账号。

平时登录 App Store 时尽量挂美区节点，用完再切回。资料里有"跨区 IP 混用会提高验证概率"的说法，具体百分比没有出处，但"美区号配美区 IP"这个方向没争议；反过来，也别一周内反复切换商店地区。

## 常见问题

**买来的号能用多久？**
平台明说无法确定使用期限，也无法保证永久有效。苹果官方有权因政策或风控收回账号，平台不承担责任。能做的是保持活跃、别长期不登录、别高频切区。

**号被封了能退吗？**
3 天售后期内，账密本身有问题（登不上、信息错误、密保不对）免费更换；3 天之后、或因自己操作不当被封，不退不换。虚拟商品一经发货不支持退款，除非是账密质量问题。

**能登 iCloud 吗？**
不建议。普通号的设计用途就是登 App Store 下载应用。确实需要 iCloud，买已激活 iCloud 那档。

**买完多久发货？**
24 小时内自动发货，多数订单几分钟到账，账号信息在购买完成页和订单中心同步显示。拿到立刻截图保存。

**能开发票吗？**
企业采购联系客服沟通，具体以客服回复为准。

**自己注册不行吗，为什么还要买？**
自己注册免费，但会卡在几个地方。目前有两条路径都有人走通：一条是从 App Store 下载免费 App 的入口进入注册流程，这时付款方式页面才会出现"无"这个选项；另一条是走 account.apple.com 网页直注，"无"不是每次都出现，需要先填完账单地址再回付款页、或退出后从 App Store 触发。前者在较新的教程里被认为是关键入口，后者在较早的教程里给出了三个兜底动作。两条路的成功率都跟账号状态、当前风控策略、注册时段有关，报错"此时无法创建你的账户"可能让人折腾一晚上。买成品号买的就是这段时间。

另外，"新号先养 7 天再充值"这个说法有分歧：卖家侧建议先只下免费 App、稳定用一阵再订阅；也有教程明确说现在不需要这道工序。比较稳妥的做法是拿到号先别急着大额充值，正常下几个免费 App 用几天，再考虑买付费应用或订阅。
